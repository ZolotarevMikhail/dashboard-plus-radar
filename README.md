# Автоматический Дашборд + Радар

Комплексный дашборд продаж для продавца на Wildberries: продажи, прибыль и
радар цен конкурентов на одном экране — с автоматическим питанием данными.
Ключевая идея — дашборд получает данные сам: ежедневная выгрузка продаж
по API и автоматический сбор цен конкурентов с открытой витрины
(раз в 3 дня, без участия человека).

Работающий демо-пример: <https://zolotarevmikhail.github.io/dashboard-plus-radar/>

## Что показывает

- **Вкладка «Продажи»** — выручка, заказы, выкуп, динамика по дням и
  товарам; короткая полоса срочных разрывов цен (от 10%).
- **Вкладка «Радар цен»** — весь разбор цен вдумчиво: ваши товары в
  парах с конкурентами, фильтр по позиции, поиск по названию, сортировка
  по разнице.
- **Прибыль** — себестоимость, комиссия WB, реклама, двойная сверка
  выгрузки API с бухгалтерией (расхождение больше 1 % видно сразу).
- **Рекомендации** — ABC-разбор и подсказки, на что смотреть в кабинете.

## Особенности

- Один файл `index.html`, без внешних библиотек и CDN — всё внутри.
- Работает из коробки: в файле встроен демо-набор (30 товаров, 2 недели).
- Адаптив: телефон (от 400 px) и компьютер; светлая и тёмная темы.
- Срез цен конкурентов, выгрузка, карта артикулов, остатки и отчёты
  реализации — имитационные данные: файлы в репо подобны настоящим, но
  числа синтетические.

## Как посмотреть

1. **Просто открыть:** двойной клик по `index.html` — дашборд покажет
   встроенный демо-набор. На GitHub Pages то же самое.
2. **С сервером (полный режим):** в папке проекта выполнить
   `python3 serve.py` и открыть <http://localhost:8765> — дашборд подхватит
   файлы данных рядом с собой (срез радара, выгрузку API, карту артикулов),
   если они есть, и покажет честные подсказки, каких не хватает.

## Автоматизация (как это работает у владельца)

Скрипты в `радар/` и `скрипты/` — рабочие механизмы проекта, показывают
подход к сбору данных без внешних сервисов:

- **Ежедневная выгрузка продаж** (`fetch-продажи.py`): ключ API лежит в
  локальном файле `.env` (в репозиторий и в код не входит), выгрузка
  инкрементальная, с автоповтором при лимитах и журналом прогонов.
- **Радар цен** (`радар-сбор.py`): настоящий Chrome в headless-режиме с
  постоянным профилем открывает открытую витрину wildberries.ru, проходит
  антибот-проверку, собирает выдачу через внутренний поисковый эндпоинт
  сайта и пишет срез JSON+CSV. Правила аналогов (`sbor-iz-brauzera.py`)
  сопоставляют товары по категориям и весу; срез записывается только если
  большинство запросов отработало (порог честности — неполный срез не
  выдаётся за свежий). Запускает macOS launchd ежедневно в 9:00, срез
  берёт раз в 3 дня — охрана расписания внутри скрипта.

Запуск скриптов требует собственных ключей и настройки расписания —
в README это подробно не описывается, код документирован внутри.
