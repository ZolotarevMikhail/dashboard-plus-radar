            Настройки

            Здесь задаются себестоимость (WB её не отдаёт) и тип товара для группировки. Значения сохраняются в браузере по артикулу.

            Себестоимость и типы товаров

            АртикулНазваниеТипСебест./шт, ₽

            Массовый импорт себестоимости

            Для большого количества товаров удобнее загрузить CSV-файл (Файл → Сохранить как → CSV в Excel). Шаблон с примером: cost-template.csv.

            Колонки (любой порядок, лишние игнорируются): vendorCode (артикул WB), nmId (числовой ID карточки), barcode (EAN-13), cost (себестоимость за шт., ₽).

            Сопоставление: сначала по barcode, затем по nmId, затем по vendorCode. Если ключ не найден — строка попадёт в отчёт «Не сопоставлено».

            Для демо-товаров типы заданы заранее. При подключении к WB список товаров поменяется — задай типы под свои товары. «Новый тип» добавляет вариант в выпадающие списки.

            Источник данных

            «Загрузить выгрузку API» берёт продажи-из-api.csv из папки дашборда — её пишет ежедневная выгрузка по API (по включению компьютера). Работает, когда дашборд открыт с сервера. Честные предупреждения: комиссия в ней упрощённая (WB не гарантирует точность), себестоимости в выгрузке нет (прибыль без закупки, себестоимость — руками). Реклама берётся из кабинета Спрутс по тем же ключам: расход по дням и товарам отдаёт рекламный API WB с 29.10.2026; в старых выгрузках (до этой даты) колонка «Реклама ₽» пустая. Точная комиссия — в блоке «Отчёты реализации» на странице: этот файл (data-api/отчёты-реализации.json) ежедневная выгрузка получает из финансового API WB сама.

            CSV-файл нужен со столбцами: date,article,qty,revenue,commission,returns,ad_spend,stock; колонка cost (себестоимость за шт) заполняет прибыль. Названия колонок понимаются и в русских вариантах («Дата», «Артикул», «Выручка»…).

            Загруженные данные сохраняются в браузере: после перезагрузки страницы дашборд покажет последнее, а не демо.

            «Загрузить демо (CSV)» показывает дашборд на тренировочном примере (30 товаров, 2 недели, с себестоимостью) — удобно проверить, как всё работает.

            Настройки (себестоимость, типы) сохраняются сразу при вводе
