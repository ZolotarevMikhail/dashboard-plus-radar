# Как пользоваться «Автоматический Дашборд + Радар»

## Запуск

- **С GitHub Pages:** открыть страницу демо — показывается встроенный
  демо-набор, всё интерактивно.
- **Локально:** двойной клик по `index.html` (тоже демо-набор).
- **Полный режим:** в папке проекта выполнить `python3 serve.py`, открыть
  <http://localhost:8765>. Дашборд сам подхватит файлы данных рядом с
  собой, если они есть: `data-snapshot.json` (радар цен),
  `продажи-из-api.csv` (выгрузка), `карта-артикулов.json`.

В репо лежат имитационные демо-файлы (`продажи-из-api.csv`,
`карта-артикулов.json`, `data-api/`), поэтому на Pages кнопки
«Загрузить выгрузку API» и блоки «Отчёты реализации» и срез остатков
тоже работают — на демо-цифрах.

## Что делать на экране

1. **Вкладки вверху страницы:** «Продажи» и «Радар цен» — разделы не
   мешаются на одном экране. На «Продажах» есть только короткая полоса
   «Срочные разрывы цен» (расхождения от 10%); весь разбор — на вкладке
   «Радар цен»: фильтр «все / дороже / дешевле / наравне», поиск по
   названию, порядок строк по разнице или по названию.
2. **Данные → «Загрузить демо (CSV)»** — тренировочный пример на 30
   товаров и 2 недели с себестоимостью (если открыли без данных).
3. **Данные → «⤓ CSV»** — загрузить свою выгрузку продаж из кабинета
   (Excel → сохранить как CSV; разделитель «;»).
4. **Настройки** — таблица товаров: себестоимость и тип (Силовые, Йога,
   Аксессуары). Правится прямо в ячейках; сохраняется в браузере.
5. **Тема** — светлая/тёмная переключается кнопкой в шапке.
6. **Период** (вкладка «Продажи») — фильтр дат в шапке; графики и ABC
   пересчитываются сразу.
7. **Экспорт** — кнопкой «Сохранить CSV» выгрузка текущего состояния
   скачивается файлом.

## Блоки

- **Панель продаж:** выручка, заказы, динамика по дням.
- **Прибыль:** после себестоимости, комиссии и рекламы; двойная сверка
  с бухгалтерией подсвечивает расхождение больше 1 %.
- **Позиция по цене (вкладка «Радар цен»):** ваши товары, рядом топ-10
  конкурентов аналога (категория и вес совпадают), рекомендация по цене.
  На главной — только срочные расхождения от 10%.
- **ABC:** вклад товаров по вкладу в прибыль с подсказками.

## Честные ограничения

- Дашборд — демо: встроенный и загруженный набор — данные для примера.
- Комиссия WB в выгрузке считается упрощённой (сам WB предупреждает,
  что точная — только в отчётах реализации с задержкой около недели).
- Все данные хранятся локально в вашем браузере.

## Что внутри

Один файл `index.html` без внешних библиотек; срез цен конкурентов —
`data-snapshot.json`; локальный сервер — `python3 serve.py` (только
раздаёт файлы, никаких ключей).
